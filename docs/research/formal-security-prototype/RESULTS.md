## Contract decisions exercised

The prototype treats the root declaration's exact raw span and its supported same-file named-reference closure as authorized source. Comments and literals inside those spans are included. Unrelated source outside the spans is forbidden. The fixture corpus is deliberately small and does not establish TypeScript semantic resolution or the behavior of every grammar form. A completed restrictive update before the final dispatch policy read is the tested ordering; a change racing after the read has no cancellation guarantee. Captured file freshness at dispatch is a separate decision.

The #99 fix reuses the same pure file-policy predicate at initial selection and queued dispatch. It does not repeat filesystem capture or Git tracking checks for an already captured unit. The #100 fix emits fixed debug categories. The original uncommitted production patch for `selection.ts` and `server.ts` had SHA-256 `24641de4e14ee670735373b57c7d8646afc003ad1751a8f3899fe1d8549efdd2` when encoded by `git diff --binary --` those two paths. The combined prototype suite passed 9 tests, typecheck passed, and direct-event conformance passed 196 tests plus manifest validation. An earlier conformance run against a slower intermediate #99 implementation hit four test timeouts; after the shared predicate change, the same command passed. The bug regression checks are distinct from the broader formal release gate, which still lacks encoded resident transport and launcher-owned diagnostics.

## Gate assessment

This prototype is **not a passing release security gate**. The following required cells remain open: an observed resident encoded HTTP request; strict connector replay against real resident queue effects; excluded host-payload discard before admission; source-file identity read and attempted-write witnesses; unexpected-error persistence through the launcher; installed-package wire and durable-sink security scenarios; and a planted direct unauthorized read/write/send caught at that process boundary. No universal PR/release enforcement was added. Existing remote branch protection and required-check configuration were not assessed.

The connector is a local uncommitted compatibility candidate, pinned by workspace path rather than a published immutable artifact. The model uses finite identities; its journal is an abstraction. Neither result establishes arbitrary TypeScript information flow, Jev server retention, or behavior of other agent hosts.
