# Hapsland logic authority map

Status: epic planning inventory, 2026-09-27. This is a source audit, not a claim that every path was exercised. The target is **one authoritative Bend transition boundary for Hapsland's product decisions**, with TypeScript supplying measured facts and executing commands. “One” means one state and entry point; internal Bend modules may remain. This map expands the original [ownership plan](../packages/agent-flow-bend/EXTENSION-PLAN.md#L69-L86), whose single instance target was not adopted, and the [completion report](bend-full-flow-completion-report.md#L55-L65).

The 2026-09-27 [review-spec amendment](issue-93-type-function-review-spec.md)
adds checked cross-file supporting evidence and larger bounded source capture
to the target. The current map describes running owners; #117/#118 must include
supporting-path eligibility before source reads, complete/incomplete graph
decisions, multi-file currentness, and the resident capacity reconciliation
tracked in [#138](https://github.com/dearlordylord/hapsland/issues/138).
The #132 migration removes the separate repository grant: file settings
select eligible files, with otherwise eligible files selected by default.
The [#118 requirements crosswalk](bend-requirements-crosswalk.md) records accepted
versus current behavior; the [generated-export inventory](bend-generated-export-inventory.md)
enumerates all 114 resident policy, seven ledger, three abstract Flow, and two
Lifecycle model wrappers with non-test static references.

## Reading the map

- **Decision**: Hapsland chooses whether, when, or what to admit, review, retain, cancel, show, or deliver. Target: canonical Bend authority unless the epic explicitly excludes it.
- **Fact/effect**: source capture, clocks, native identities, Jev request and response, bytes actually encoded, IPC, and cancellation execution. TypeScript performs these; Bend receives facts about them. See [plan boundary](../packages/agent-flow-bend/EXTENSION-PLAN.md#L69-L79).
- **Projection**: display text, diagram geometry, explanation formatting, or metrics derived from an authoritative decision. This can remain TypeScript if it cannot alter an outcome.
- **Verified call site** below means a static import and call were found in a production source path. It does not prove that every runtime configuration or host reaches that call. **Model/test only** means no resident import of that aggregate was found in the searched sources.

## Dependency and migration decision

### Runtime reachability and state ownership checkpoint

Static wrapper references are enumerated in the [export inventory](bend-generated-export-inventory.md). The supported installed-release [conformance profile](../conformance/installed-release-v1.json), [direct-event profile](direct-event-v1-supported-profile.md), and [resident tests](../src/resident/server.test.ts) witness the resident/direct path only for their declared host, event, and fixture scope. The `server.ts` → `prepareObservation`/`evaluatePrepared`/`ComposedDelivery` route is exercised by these tests; this does not show that all 114 generated wrapper branches execute. The [`cli.ts`](../src/cli.ts) → [`runtime/review.ts`](../src/runtime/review.ts) path is statically callable and has its own unit tests, but no installed host witness was found here. The removed `src/policy/index.ts` re-export of `eligibility.ts` had no found production import. `Flow.step` is exercised by the page and browser tests; `Lifecycle.apply` is exercised by its trace checker, not the resident. These reachability classes must remain separate when retiring paths.

Scope is settled for this epic: authored scheduling order, effective configuration precedence/defaults, file selection, supported-reference follow/skip and completeness, rule applicability, threshold/finding derivation, ranking, and budget are **product decisions owned by the canonical Bend transition**. Native parsing, strict schema decoding, glob/path matching, physical containment and Git-ignore observations, clocks, source capture, exact encoded bytes, Jev inference, sockets, and output writes remain TS **fact/effect** work. Presentation labels, layout, and source-free status formatting are TS **projections**. There is no standing product-decision exception for these families. The executable boundary checks are the shared adapter's compiled-ABI variant tests, import restrictions on resident/page consumers, and contract traces for path refusal before read, no Jev request for incomplete units, ordered partial capacity, and stale output. If a later slice needs an exception, it must name the decision, reason, owner, and executable check before accepting it.

The current graph is **not five independent full implementations**. `Lifecycle.apply` imports `Admission`, `Work`, `Handoff`, and `Round`; the modules do not import the aggregate ([imports](../packages/agent-flow-bend/Lifecycle.bend#L1-L5)). `Work` imports only capacity primitives from `Flow`, not `Flow.step` ([references](../packages/agent-flow-bend/Work.bend#L169-L195)). Production calls many generated functions from these Bend modules and composes their state in TypeScript; it does not import either aggregate's `step`/`apply` ([static call search](../packages/agent-flow-bend/README.md#L20-L34)). The two diagram reducers are duplicates over a narrower model, while production has several additional decision owners.

**Recommended endpoint: evolve `Lifecycle.apply` rather than add a sixth aggregate.** It already has the intended state/event/command shape and the richer admission/work/finish dependency. Extend that *same* type and entry point to cover Round, collection, leases, ticket/revision/reuse/cache/notices/retention, scheduler decisions, and a global ledger state as scope requires. Adapt its event names to facts observed at the real barriers. Route production through it, then remove superseded direct wrapper calls and TypeScript state decisions slice by slice. Collapse the older `Handoff.Finish` path and the production `Lifecycle.finish_gate`/`finish_output` path into one finish state and transition sequence. `Flow.step` then becomes a temporary diagram oracle and is retired after the page uses canonical events; shared capacity helpers can survive in another Bend module. This is **replacement/evolution**, not an additional permanent authority. It is an architectural recommendation; no migration has yet been implemented.

Alternative: evolve `Flow.step` into the canonical endpoint, importing or relocating the richer modules and replacing its packet IDs with observation/unit/lease/ticket identities. That would preserve the name but replace most of the reducer's present state and events. Its simplified assumptions ([state/events](../packages/agent-flow-bend/Flow.bend#L35-L68)) make this a larger rewrite than extending `Lifecycle`; preserving both reducers throughout migration would extend the current split. Decide the final module name separately from state ownership if `Flow` is important product vocabulary.

## Remaining implementation and verification gates for the epic

1. Turn the [complete static export list](bend-generated-export-inventory.md) into verified runtime coverage as each vertical slice lands. In particular, check the CLI legacy `review` route, the unconsumed `src/policy/index.ts` barrel, and non-installed `ComposedDelivery` branches ([legacy branch comment](../src/resident/composed-delivery.ts#L260-L268)). Static references alone do not establish supported-host reachability.
2. Enforce the settled scope with compiled ABI and import-boundary checks. Path resolution and source capture remain native facts/effects, while the decision to follow, omit, or mark a unit incomplete belongs to Bend. Split mixed branches before retiring each TS decision owner.
3. Verify the state ownership table above against exact partition/global ledger atomicity, 256 KiB capture and 20 KiB evidence trees, Stop/handoff races, and wrapper arguments such as `binding_valid`, `can_write`, and `extra_unfinished`: these may hide policy conclusions rather than measured facts ([finish signature](../packages/agent-flow-bend/Lifecycle.bend#L253-L261), [finish gate](../packages/agent-flow-bend/Lifecycle.bend#L73-L82)).
4. Keep independent source-free contract traces across the migration. Current sidecar parity tests a finite abstract overlap and the UI records inputs accepted by TS first ([research](sidecar-sunset-research.md#L16-L18)); neither proves the canonical production boundary.

Confidence: **high** for the cited ownership/import/call topology and the explicit scope decision; **medium** for proposed migration ordering and mixed-branch decomposition; **open** for every generated branch's production reachability and behavior under all host/IPC races. The [requirements crosswalk](bend-requirements-crosswalk.md) records the contract evidence and unresolved specification details.
