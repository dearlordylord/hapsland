## Reading the map

- **Decision**: Hapsland chooses whether, when, or what to admit, review, retain, cancel, show, or deliver. Target: canonical Bend authority unless the epic explicitly excludes it.
- **Fact/effect**: source capture, clocks, native identities, Jev request and response, bytes actually encoded, IPC, and cancellation execution. TypeScript performs these; Bend receives facts about them. See [plan boundary](../packages/agent-flow-bend/EXTENSION-PLAN.md#boundary-and-source-of-truth).
- **Projection**: display text, diagram geometry, explanation formatting, or metrics derived from an authoritative decision. This can remain TypeScript if it cannot alter an outcome.
- **Verified call site** below means a static import and call were found in a production source path. It does not prove that every runtime configuration or host reaches that call. **Model/test only** means no resident import of that aggregate was found in the searched sources.

## Dependency and migration decision

### Runtime reachability and state ownership checkpoint

Static wrapper references are enumerated in the [export inventory](bend-generated-export-inventory.md). The supported installed-release [conformance profile](../conformance/installed-release-v1.json), [direct-event profile](direct-event-v1-supported-profile.md), and [resident tests](../src/resident/server.test.ts) witness the resident/direct path only for their declared host, event, and fixture scope. The `server.ts` → `prepareObservation`/`evaluatePrepared`/`ComposedDelivery` route is exercised by these tests; this does not show that all generated wrapper branches execute. The [`cli.ts`](../src/cli.ts) → [`runtime/review.ts`](../src/runtime/review.ts) path is statically callable and has its own unit tests, but no installed host witness was found here. The removed `src/policy/index.ts` re-export of `eligibility.ts` had no found production import. The page and browser checks exercise `Canonical.step` through the shared adapter; `Flow.step` has no active consumer, and `Lifecycle.apply` is exercised by its trace checker only. These reachability classes must remain separate when retiring paths.

Scope is settled for this epic: authored scheduling order, effective configuration precedence/defaults, file selection, supported-reference follow/skip and completeness, rule applicability, threshold/finding derivation, ranking, and budget are **product decisions owned by the canonical Bend transition**. Native parsing, strict schema decoding, glob/path matching, physical containment and Git-ignore observations, clocks, source capture, exact encoded bytes, Jev inference, sockets, and output writes remain TS **fact/effect** work. Presentation labels, layout, and source-free status formatting are TS **projections**. There is no standing product-decision exception for these families. The executable boundary checks are the shared adapter's compiled-ABI variant tests, import restrictions on resident/page consumers, and contract traces for path refusal before read, no Jev request for incomplete units, ordered partial capacity, and stale output. If a later slice needs an exception, it must name the decision, reason, owner, and executable check before accepting it.

The current graph includes one production aggregate, [`Canonical.step`](../packages/agent-flow-bend/Canonical.bend), with a checked [adapter](../src/canonical/adapter.ts). The resident calls that boundary at integrated decision barriers and still calls generated policy modules for other decisions, as the [Bend README](../packages/agent-flow-bend/README.md) describes. `Lifecycle.apply` remains a separate checked model; `Work` imports capacity primitives from `Flow`, but no active page or production path calls `Flow.step`. The page replays the production aggregate from source-free inputs, while native observations and effects remain TypeScript work. #117 still needs to assess each retained owner and generated export against this current graph.
